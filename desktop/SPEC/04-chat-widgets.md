## Purpose

This area is the whole visible chat surface except the list container itself (`chat.dart`) and the moderation/mod-tools leaves: how one chat line is drawn (`ChatMessage`: PRIVMSG/USERSTATE lines with reply/first-message/cheer/highlight/redemption headers, timeouts/bans/deletions with reveal-on-tap, NOTICE lines with actions, USERNOTICE rows), Twitch notice rows in the signal lime (`UserNoticeRow`), gift-bomb recipient lists, power-up animated message frames, raid welcome cards, clip/VOD link preview cards with a shared request queue, chat GIFs (animated or first-frame only), FrankerFaceZ emote modifiers (motion + colour matrices on one shared ticker), 7TV name paints (gradient/image shaders), the composer (`ChatBottomBar`: restriction line, reply preview, emote/command/mention autocomplete, the pill text field with inline emote rendering, character counter, pop-in send disc, channel points pill, "⋯" details button, pencil mode for narrow side chats), chat tabs for multi-channel chat (reorder, merge, disconnect, remove, add-chat search sheet), and every sheet and dialog reachable from chat: message options, reply thread, filtered-message "Message Blocked", user card (sheet or tablet panel) with badges/account age/follow age/moderation pills/timeout menu/reason dialogs/recent messages, unban request, warning acknowledgement, lead-moderator confirmation, chat badge picker, chat rules (prompt before typing + menu entry), shared chat banner, live-together (guest star / co-stream) roster, shoutout card, the channel points pill and its sheet (balance, intro, resub share, drops, community moment, weekly rewards, hype chests + reveal, watch streak + help, Bits/gift tallies, bonus chest with "+N" burst, predictions with bet sheet, terms/moderator/spectator dialogs, rewards with redeem dialog and emote-unlock picker), community/challenges/creator goals/leaderboards sheets.

Fork context: ONSET replaces the Twitch web player with a native low-latency player; none of this chat layer may lose a feature. On PC the rewrite must reproduce every one of these surfaces, states and wordings (EN + FR).

## Behaviour and state

Ownership of state:
- Chat-wide state lives in `ChatStore` (MobX, chat leaf): `messages`, `revealedMessageIds` (deleted messages revealed by tap), `revealedFilteredMessageIds` (filtered messages shown via "Show Message"), `replyingToMessage`, `textController`, `textFieldFocusNode`, `expandChat`, `restriction`, `isConnected`, `hasConnected`, `isWaitingForAck`, `showSendButton`, `matchingEmotes`/`matchingChatters`/`matchingCommands`, `showEmoteAutocomplete`/`showMentionAutocomplete`, `expandedGiftBombs` + `watchGiftBomb(key)`, `canModerate`, `canPinMessages`, `whispers`, `modTools`, `assetsStore` (emote maps, badges, `showEmoteMenu`, channel profiles), `settings` (SettingsStore). Widgets re-render via `Observer`.
- Channel-points state lives in `ChannelEventsStore` (channel leaf), provided by Provider only on the channel screen (absent in the mini player): `points` (CommunityPointsContext: balance, pointsName, image, rewards, activePrediction, hasClaim, hasAnything), `watchStreak`, `resubNotification`, `bitsBalance`, `giftedSinceJoining`, `dropCampaigns`, `claimingDropId`, `moment`, `weeklyRewards`, `legendaryCollection`, flags (`pointsActionInFlight`, `openingChests`, `canOpenChests`, `claimingMoment`, `canClaimMoments`, `canShareWatchStreak`, `sharingWatchStreak`, `canShareResub`, `sharingResub`, `canUnlockEmotes`, `hasCommunityGoals`, `hasLeaderboards`) and actions (redeem, unlock, claim bonus, predict, accept terms, share streak/resub, claim drop, open chests, claim moment, contribute to goal, loaders).
- Local widget state: link preview future, gift-bomb expansion (mirrored to the store because rows are recreated as messages flow), moderation bar busy/last outcome/menu open, unban sheet loading/sending/error, badge sheet identity/busy, add-chat debounce/results, bet stake, emote-unlock picks, streak help open, restriction countdown ticker, panel bet view (`_betOn`/`_betPrediction`/`_betAccess`).

Key behaviours (details per file):
- Tap on a chat row: dismisses the keyboard and closes the emote menu. Long press: light haptic; notice rows → copy sentence + message; non-PRIVMSG lines → copy text; PRIVMSG/USERSTATE → options sheet (Copy, Copy and paste into the composer, Reply, Report (in-app report flow, browser fallback), Pin (moderator with web session, own channel only), Delete (moderator rules: not the broadcaster's line, not another mod's unless broadcaster)). Copy shows a "Message copied" toast in the composer's notification area.
- Name tap → user card (not for own name, not for lines without user id, not inside sheets). @mention tap → fetch user via Helix then card.
- Deleted/banned messages: header label at 50 % opacity ("Message deleted", "Permanently banned", "Timed out for N"), text shown when "Show deleted messages" is on (default on), otherwise a tappable placeholder reveals that one message for the session.
- Chat filters (Twitch's discrimination/sexual/hostility/profanity filters, client-side): hidden ranges drawn as stars; tap → "Message Blocked" sheet → "Show Message" reveals that message. Moderators always see everything. Hidden links are never previewed.
- Link previews: first clip or VOD URL of a message (first 50 words) → fixed-height 64 dp card, global cache (64 LRU, 3 concurrent, 8 queued with oldest dropped, failures retried after 60 s), tap opens in-app.
- Notice visibility: all USERNOTICE rows, highlighted messages, redemption headers and power-up frames require `showsNoticesIn(channelId)` (global "show user notices" AND channel not in the hidden list).
- Composer enablement: logged in, connected, not waiting for Twitch's ack, not timed out / in slow-mode wait. A ban does NOT disable sending (Twitch gives no unban signal; a send reveals the state). Hint text explains the blocking reason in priority order. Message length hard-capped at 500 grapheme clusters; counter appears at < 50 left, red at ≤ 10.
- Autocomplete: emotes (exact images, tap inserts, long-press shows emote details), commands (tap fills `/name `), mentions (tap replaces the current word with `@name `).
- Narrow landscape side chat (< 30 % width with video visible and chat not expanded): the text field is replaced by a pencil button that expands the chat and focuses the field; controls scale down to fit.
- Chat tabs: up to 10 channels; primary tab cannot be removed; others can be disconnected (kept but inactive, greyed) or removed; reorder by drag with haptic; merge mode when ≥ 2 activated tabs shows one merged list (active tab = send target; reply/paste switch to the message's source tab first).
- Android back inside chat: closes emote menu, then unfocuses the keyboard, then navigates back. iOS: normal pop.
- User card: header actions (Reply inserts `@login `, Whisper opens a conversation when the whisper store exists, Profile opens the channel profile, More opens user actions), badges with months, account creation date, follow date (moderators only, not for the broadcaster), moderation (mod pills, timeout menu, ban, unban, warn, "More actions"), recent messages (newest at bottom, live).
- Moderation outcomes are shown inline under the pills via the status line (spinner while running), never leaving buttons disabled after an exception.
- Points flows capture the `ScaffoldMessenger` before awaiting so a result is reported even if the sheet/panel closed (rotation closes tablet panels) — except `_openChests`, which returns on `!mounted` before its failure snackbar (see Known Android defects). Outcome snackbars via `_say`/`_report`: 2 s success, 6 s refusal; streak share, resub share, drop claim and chest-open failure snackbars use the default 4 s. Integrity refusals add a "connect twitch.tv session" action.
- Predictions: moderator confirmation when Twitch flags the viewer as a moderator of the channel; spectator mode (stake 0) in restricted regions/categories; terms dialog on first bet (and accept-terms call), one automatic retry after a "must accept terms" refusal; the bet happens in a bet sheet (phone) or replaces the list inside the panel (tablet), and a bet view never carries over to a new prediction.
- Rewards: affordable + redeemable → confirm dialog (with message field when required, 200 max); chosen-emote unlock rewards → emote picker (and modifier picker for modified unlocks); out-of-reach rewards are dimmed (50 %) with no tap target.
- Bonus chest: Collect button (disabled while any points action is in flight) or an integrity-blocked explanation; on success with a measurable gain, a "+N" burst pops above the button.

## Animations and motion

Every animation in the area (reduce motion = `reduceMotionOf`, unless noted `MediaQuery.disableAnimations` only):
1. `PowerUpMessageFrame` (power_up_frame.dart): AnimationController 3000 ms, `repeat(count: 4)` (12 s total) started in didChangeDependencies when value is 0; linear; a diagonal LinearGradient (colours per animation id + first colour repeated, `TileMode.repeated`) whose begin/end alignments shift by −2·t, painted only into the 4 dp left bar by a CustomPainter. Reduce motion → `stop()` freezes the gradient wherever it is (t = 0 if it never started). After the 4 loops it rests at `(elapsed mod 3 s)/3 s`, a small non-zero frame-dependent value (visually ≈ t = 0). Because `repeat` only starts when value == 0, turning reduce motion off again after a mid-run freeze never resumes it (Known Android defects).
2. `RaidWelcomeCard._Rule`: TweenAnimationBuilder 510 ms; vertical scale from the top = `standard` curve over [90 ms, 510 ms] (90 ms delay, 420 ms draw). `_Pop` (rocket): TweenAnimationBuilder 580 ms; local p over [60 ms, 580 ms]; first 55 %: scale 0.35→1.1, rotation −12°→+3° (standard curve), opacity 0→1; last 45 %: scale 1.1→1.0, rotation 3°→0° (standard curve). Only when the card is < 4 s old and not reduce motion; otherwise static.
3. `GiftBombRecipients`: chevron `AnimatedRotation` 0 ↔ 0.5 turn, 220 ms, `standard` (0 ms under reduce motion); list `AnimatedSize` 220 ms `standard`, top-start aligned, clipped (instant swap under reduce motion).
4. `ChatBottomBar._GrowIn` (autocomplete rows): 260 ms `standard`, SizeTransition growing from the bottom edge (axisAlignment 1), once on first appearance; reduce motion → FadeTransition with 150 ms. A single CurvedAnimation per row (no listener leak per keystroke — tested).
5. `ChatBottomBar._PopIn` (send disc): AnimatedSwitcher `motionDuration(220 ms)`, in `standard`, out `emphasizedAccelerate`; fade + scale 0.97→1 + slide from 6/36 of its height (6 dp) below; reduce motion → fade only, 150 ms.
6. `ModerationPill` chevron: AnimatedRotation 0 ↔ 0.5 turn, `motionDuration(220 ms)`, `standard`.
7. `AnimatedScrollBorder`: AnimatedSwitcher 200 ms, in `Curves.easeOut`, out `Curves.easeIn`, cross-fade divider ↔ transparent divider (not reduced).
8. `FfzModifiedEmote`: one global Ticker (`FfzModifierClock`) driving seconds; slide/appear/disappear 2 s cycles, rotate 1.5 s per turn, jam (0.6 s sway ±0.25 rad, 0.3 s hop 8 % of height), bounce (0.8 s, 25 % of height), hyperShake (sin 61 t, cos 47 t, ±2 px), rainbow hue rotation 2 s cycle. Linear time. Frozen at t = 0 when animate-emotes is off, inside an inactive TickerMode, or `MediaQuery.disableAnimations`. Ticker stops when no listener remains.
9. `ChatGifImage`: animated GIF frames (decoder-driven) unless "Animate GIFs" is off → `FirstFrameImage` still. No fade-in (`useFade: false`).
10. `PaintedName`: animated image paints update each decoded frame (image stream listener).
11. `_PredictionCard` share bars: TweenAnimationBuilder from previous to new share, `motionDuration(420 ms)`, `standard`.
12. `StreakHelp` body: AnimatedSize 220 ms `Curves.easeOutCubic`, top-left (not reduced).
13. `_EverySecond` / `ChatRestrictionBar` countdowns: 1 s periodic rebuilds (not animations, but visible ticking).
14. `PointsBurst`: unbounded controller driven by `SpringSimulation(mass 1, stiffness 260, damping 18, 0 → 1, v 0)` for the pill scale (clamped 0–1.4, overshoot); life controller 1400 ms: rise 0 → −18 px with easeOutCubic, opacity 1 until 75 % then linear to 0, particles progress = min(1, 1.4·t). `MediaQuery.disableAnimations` → static (scale 1, life 0.5) and removal after 900 ms.
15. `ParticleBurst` painter: deterministic (seeded) circles flying outward, distance easeOutCubic, alpha 1 − easeIn, radius shrinking by up to 50 %, alternating accent/white.
16. `ChestRevealSheet`: controller 900 + 90·n ms; per-emote elastic pop (`Curves.elasticOut`) staggered over the first 45 %, each lasting 55 % of the timeline; 28-particle burst; empty reveal fades the box icon in. `MediaQuery.disableAnimations` → value 1 at once.
17. `ChatTabs` reorder: ReorderableListView default drag lift/settle animations, transparent proxy.
18. Material defaults: InkWell ripples on rows/chips/pills, `CircularProgressIndicator`/`LinearProgressIndicator` (indeterminate spinners in loading states; determinate bars static), SnackBar enter/exit, MenuAnchor open/close, dialog and bottom-sheet transitions (the sheet kit), tablet panel fade (panel kit).
19. Shared chat banner (in chat.dart, uses this area's widget): AnimatedSwitcher 240 ms (150 reduced), in emphasizedDecelerate / out emphasizedAccelerate, Fade + SizeTransition from the top.
Haptics: long press on a chat line → light impact; emote chip long press → light impact; tab reorder → light impact; tab select/merge → selection click; tab disconnect/remove → light impact; chests opened → heavy impact.

## Settings

Settings read by this area (SettingsStore key = default → effect):
- `showDeletedMessages` = true → deleted/banned messages show their text (else tappable placeholder; reveal per message).
- `chatFiltersEnabled` = false → applies Twitch-style chat filters (`ChatFilterSettings.of(settings)` reads the per-category filter settings); hidden ranges starred, tap to reveal; moderators exempt.
- `hideGiftCount` = false → notice sentences omit the gifter's total gift count when true.
- `emoteScale` = 1.0 → emote size = 28 × scale in chat lines; in the composer it is only the fallback height (an emote's native `height` wins, see emote_text_span_builder.dart).
- `badgeScale` = 1.0 → badge size and message header icon size = 18 × scale.
- `animateEmotes` = true → animated emotes and FFZ motion modifiers.
- `showGifs` = true → chat GIFs drawn as images (else their title as text).
- `animateGifs` = true → GIFs animate (else first frame only).
- `nameColorContrast` (computed) → `increaseChatContrast` (default false) ? 7.0 : `readableNameColors` (default true) ? 4.5 : null — minimum contrast applied to chatter name colours.
- `launchUrlExternal` = false → links open in the external browser instead of in-app.
- `timestampType` = `TimestampType.disabled` → message timestamps (`disabled`, `twelve`, `twentyFour`).
- `highlightFirstTimeChatter` = true → first-message highlight (#B15CFF bar + "First message" header).
- `showsNoticesIn(channelId)` → `showUserNotices` (default true) && channel not in `noticesHiddenChannelIds` (default empty) — gates USERNOTICE rows, highlighted messages, redemption headers, power-up frames.
- `showLinkPreviews` = true → clip/VOD preview cards.
- `messageSpacing` = 8.0 → vertical padding of each line = spacing/2 top and bottom.
- `showChatMessageDividers` = false → a themed Divider under each line (the app's DividerThemeData: space 0.5 dp, thickness 0.5 dp, colour `onsetColors.hairline` = white 8 % dark / black 8 % light — theme.dart; NOT Material's 16 dp default).
- `chatBubbleEvents` = [] (subset of subs, gifts, raids, announcements, other) → those notice kinds render as rounded bubbles instead of accent-bar rows.
- `messageScale` = 1.0 → text scale in reply thread and user card recent messages.
- `fontSize` = 12.0 → chat font size (reply thread, user card messages, reply preview).
- `showTwitchEmotes`, `show7TVEmotes`, `showBTTVEmotes`, `showFFZEmotes` = true → if all false, no emote-menu button.
- `autocomplete` = true → autocomplete rows.
- `emoteMenuButtonOnLeft` = false → emote button as the field's prefix (field padding 4) instead of in the suffix.
- `chatWidth` = 0.2 (fraction of screen width in landscape side chat) → pencil mode below 0.3.
- `showVideo` = true → pencil mode and delay hint need the video visible.
- `effectiveChatDelay` (computed: `autoSyncChatDelay` default true ? synced delay : `chatDelay` default 0) → "delayed" hint text with seconds when > 0.
- `fullScreen` = false → with landscape, the bar is drawn without the blurred gradient container.
- `landscapeForceVerticalChat` = false → affects bottom safe-area padding in landscape.
- `pointsIntroSeen` = false → shows the channel points intro card until dismissed (sets it true via `runInAction`).
Settings are read inside MobX Observers so changes re-render immediately (tested for badge scale and name colours).

## Network and data

Calls made from, or injected into, widgets of this area (services extend `BaseApiClient`; GQL ones use the viewer's twitch.tv web token `auth.twitchWebToken` when present):
- `TwitchApi.getUser(userLogin)` — @mention tap in a chat line (ChatMessage) → open card; `TwitchApi.getUser(id)` → account creation date (UserCardInfo); `TwitchApi.getFollowedAt(broadcasterId, userId)` → follow date, moderators only (UserCardInfo); `TwitchApi.searchChannels(query)` → add-chat search, debounced 300 ms (AddChatSheet). Failures: mention → nothing; user card lines omitted; search → "Couldn't search channels."
- `TwitchClipService.getClip(slug)` / `TwitchVodService.getVideo(vodId)` — link preview cards via the `ChatLinkPreviews` queue (dedup, 3 concurrent, 8 queued, 64 cached, 60 s retry for failures/empty/no thumbnail). Thumbnails only from `https://*.jtvnw.net` / `https://*.twitch.tv` without port/userinfo, not `404_processing`. Non-API errors reported to Telemetry ("chat link preview").
- Images: emotes, badges, GIFs, avatars and paints via `OnsetCachedNetworkImage`/`CachedNetworkImage` with the app's `CustomCacheManager`; reward/points/weekly badge images via `Image.network` (no disk cache), points icon at 2× (pill) and 4× (sheet header).
- `TwitchCommunityService.getUnbanRequest(channelId, authToken)` and `TwitchViewerActionsService.createUnbanRequest(channelId, message ≤ 500, authToken)` (unban sheet). `getChatIdentity(channelId)` / `selectBadge(scope, channelId, badge)` / `setSubFlairHidden(hidden)` (badge sheet, wired in chat details). `getShoutoutProfile(channelLogin, targetLogin, authToken)` (shoutout card, wired in chat.dart). `getGuestStarSession(channelId)` + `getCostreamers(channelLogin)` combined by `loadLiveTogether`.
- `ChatStore.acknowledgeWarning(service)` (warning dialog), `ChatStore.moderate(command, userId)` (moderation bar, delete message: Helix moderation endpoints / IRC commands in the chat leaf), `ChatStore.pinMessage(id)`, `ChatStore.sendMessage(text)`.
- `ChannelEventsStore` (channel leaf) GQL actions triggered from the points UI: `refreshWatchStreak()` and `refreshDrops()` on opening the points sheet (≤ once a minute), `redeemReward(reward, userInput)`, `loadUnlockableEmotes()`, `unlockChosenEmote(reward, emoteId)`, `claimBonus()`, `predictionAccess(eventId)`, `acceptPredictionTerms(temporaryBadgeEnabled)`, `placePrediction(eventId, outcomeId, points)`, `shareWatchStreak()`, `shareResub(message)`, `claimDrop(drop)`, `openChests()`, `claimMoment()`, `loadCommunityGoals()`, `contributeToGoal(goal, amount)`, `loadLeaderboards()`.
- Links opened: twitch.tv security settings (`https://www.twitch.tv/settings/security`, in-app via LinkRouter), prediction terms (`https://www.twitch.tv/p/legal/predictions-terms-and-conditions/`, external app), drops account-link URL (external app), clip/VOD URLs (in-app LinkRouter), report fallback URL (`twitchReportUri`).
- Clipboard: copy message, copy notice text.
- No persistence written by widgets except `settings.pointsIntroSeen = true` and the chat store's gift-bomb expansion set (in memory).

## Wide and tablet layout

"Large screen" = shortest side ≥ 600 dp (or a `LargeScreenScope` override). Rules:
- `showSheetOrPanel` decides per open: with an anchor rect and a large screen, `placePanel` tries the listed sides within the screen minus system insets and a 12 dp margin, 12 dp gap from the anchor, lining up inside the chat column (`PanelRegion`) for above/below, centred on the anchor (slid under the video if it would cover it, `PanelAvoidScope`) for left/right; if nothing fits → regular bottom sheet. Panels are drawn by `OnsetPanelSurface` (20 dp radius, #181818 tone, nub pointing at the anchor), close on rotation/resize, and `SheetPresentation.isPanel(context)` lets content switch to dense sizes.
- User card: panel 384×344, sides left, right, above, anchored on the tapped chat row (phone: 470 dp sheet). Dense mode: header padding top 12 / right 6, avatar radius 22, badge pills 26 dp on `chip` with no ring (18 dp images, 11.5 text), date glyph 13, date text 12, moderation pills 40 dp with 5 dp spacing, status line min 28, divider top margin 2, no "RECENT MESSAGES" label, messages top padding 10, sheet height not fixed; collapses to a scrolling column under 280 dp (380 on a phone).
- Channel points: panel 384×562 above (else below) the points pill; content not height-capped (fills the panel), list not shrink-wrapped, header top padding 14; the bet view replaces the list in the same panel with a Back chevron; reward rows 56 min (60 phone) with 34 dp tiles (36), 14 dp titles (14.5), 10 dp cost ring (11), 12 dp cost (12.5); cards inside the panel use #202020 (dark) instead of the well colour.
- Sub-sheets opened from the panel (community, goals, leaderboards, emote unlock, hype chests, shoutout): `showOnsetSheet(panel: true)` with max width 560 (centred bottom sheet in the #181818 tone); when presented inside a panel their max height is unbounded and header top padding is 14 instead of 6.
- Chat bottom bar: tablet portrait ("large") → input pill 48 dp, text 15 sp, top padding 8, prefix min width 44, points pill 48 dp (14 dp side padding, 7 dp spacing, 14 sp balance), "⋯" 48 dp. A tablet side chat with a header "⋯" (`ChatMoreInHeader`) omits it from the input row. When the emote menu is a tablet panel (`emoteMenuInline: false`) the bar keeps its bottom safe-area padding.
- Landscape phone side chat: pencil mode below 30 % width; controls FittedBox-scaled at the 20 % minimum; GIFs 72 dp.
- Leaderboards/community goals entry functions constrain to max width 560.

## PC equivalent

Windows (Slint UI, Rust; macOS/Linux later). Mapping, keeping every feature:
- Chat line: hover highlight (the InkWell ripple becomes a subtle hover background); left click on a line = unfocus composer + close emote menu; right-click (and Shift+F10/Menu key, and long-press on touch screens) opens the message options as a context menu or anchored popover listing exactly the same rows (Copy message, Copy into message box, Reply, Report (opens the report flow/browser), Pin, Delete in danger colour) with the message preview card at the top; notice rows' context action = copy sentence + message; Ctrl+C on a hovered/selected line copies it. Name and @mention are hyperlinks (pointer cursor, underline on hover) opening the user card as an anchored popover beside the line (the tablet panel logic is the default on desktop: 384×344, left/right/above). Reveal-deleted and filtered placeholders are clickable with a tooltip.
- Link cards: 64 px row, hover state, click opens in the in-app player/browser; middle-click/Ctrl+click opens externally.
- Composer: multi-line text box (1–3 lines) with inline emote images (rich text spans; the caret treats an emote as its source word); Enter sends (the field soft-wraps up to 3 visible lines; no newline is ever inserted, matching `TextInputAction.send`); Esc cancels reply, closes autocomplete, then emote menu, then unfocuses (mirrors Android back priority); Up/Down or Tab/Shift+Tab move through autocomplete chips, Enter/Tab accepts, Esc dismisses; Ctrl+E (or a configurable shortcut) toggles the emote menu; the 500-character limit and counter identical. Pencil mode is unnecessary when the side chat is wide enough but must be kept for a narrow docked chat (< 30 % of window width with video): a pencil button expands the chat.
- Restriction line, reply preview, autocomplete rows, send disc pop-in, character counter: same sizes in logical pixels, hover states on chips, tooltips on icon buttons (Emote menu, Send/Sending…, More, Cancel reply).
- Chat tabs: a horizontal tab strip with drag-to-reorder (mouse), middle-click or the ✕ opens the Disconnect/Remove menu (right-click on a tab too); Ctrl+Tab / Ctrl+Shift+Tab cycle tabs; Ctrl+1…9 select; merge toggle button with tooltip; "Add chat" opens a search dialog (300 ms debounce) with keyboard navigation (Up/Down, Enter selects, Esc closes).
- Sheets → desktop popovers/dialogs: phone bottom sheets become centred modal dialogs or anchored popovers (≤ 560 px wide) with the same content, scrim black 62 %, Esc closes, focus trapped, scroll with wheel; the channel points sheet is an anchored popover (384×562) above the points pill; the bet view replaces its content with a Back button (Alt+Left / Backspace also go back); the timeout menu is a context menu above the Timeout pill with keyboard navigation; moderation pills row scrolls horizontally with the wheel (Shift+wheel) and shows the end fade.
- Dialogs (`OnsetDialog`): Enter = primary action when enabled, Esc = cancel; destructive Ban uses the danger tone; text fields with counters.
- Animations: reproduce durations/curves exactly with Slint animations or a custom timeline (cubic-bezier tokens, spring for the points burst: mass 1, stiffness 260, damping 18); honour Windows "Show animations in Windows" (SPI_GETCLIENTAREAANIMATION) as reduce motion; FFZ modifiers on one shared frame clock that stops when no modified emote is visible; GIFs/animated emotes decoded with frame timing, a still-first-frame mode when "Animate GIFs"/"Animate emotes" are off; 7TV paints via gradient brushes or image-pattern fill clipped to text (render text to a mask, fill with the gradient/image tiled to text height).
- Haptics have no PC equivalent; replace with nothing audible (optionally a subtle visual press). Snackbars → toast area at the bottom of the chat/window with the same durations and action buttons (Undo, Connect).
- Clipboard via the OS clipboard; external links via the default browser (ShellExecute), in-app links via the app's router.
- Accessibility: expose the same semantic labels/hints (UI Automation names), live regions for the countdown/character counter/burst, `expanded` state on gift-bomb toggle and streak help, header roles on titles.
- Overlay chat frame (chat over the video in fullscreen, `overlay_chat_frame.dart`, other leaf) uses `OverlayChatScope`: translucent 16 % black notice rows with 6 px radius, compact GIF height 72.


### Known Android defects

Real bugs in the Android build. The PC port fixes each one; the Android behaviour is recorded so nothing changes silently.

| # | Android behaviour (exact) | PC port behaviour |
|---|---|---|
| 1 | `_openChests` (channel_points_sheet.dart) returns at `if (opening == null \|\| !mounted) return;` before its failure snackbar: if the panel closed (rotation) the failure is never shown. | Report the failure through the captured messenger whenever the toast host still exists, like the other points actions. |
| 2 | Points snackbars are inconsistent: streak share, resub share, drop claim and chest-open failure use the default 4 s, other outcomes 2 s / 6 s. | Keep the visible wording; use 2 s success / 6 s refusal for every points outcome. |

`FfzModifiedEmote(modifiers, animate, width, height, child, clock?)`: `still` = !animate (setting animateEmotes) || !TickerMode.of(context) (inactive tab) || `MediaQuery.disableAnimationsOf(context)` (reduce motion). still or no moving bit → `frame(0)` (static: flips, rotate90 and colour filters still apply at t = 0). Else `AnimatedBuilder(animation: clock ?? instance)` → `frame(seconds)`.

`frame(seconds)` (@visibleForTesting): colour matrix (if any) → `ColorFiltered(ColorFilter.matrix)`; transform = `motion(...)` × `diag(flipX ? −1 : 1, flipY ? −1 : 1, 1)`; rotate90 → `rotateZ(π/2)`; identity → no Transform; else `Transform(alignment: centre, transform)`.

`motion(modifiers, seconds, width, height)` (static, @visibleForTesting) with `cycle(s, period) = (s mod period)/period`:
- slide: dx += (cycle(2)·2 − 1)·width (slides across −w → +w every 2 s).
- appear: dx += (cycle(2) − 1)·width (from −w to 0 every 2 s).
- disappear: dx += cycle(2)·width (0 to +w every 2 s).
- rotate: angle += cycle(1.5)·2π (one turn per 1.5 s).
- jam: angle += sin(cycle(0.6)·2π)·0.25 rad; dy −= |sin(cycle(0.3)·π)|·height·0.08.
- bounce: dy −= |sin(cycle(0.8)·π)|·height·0.25.
- hyperShake: dx += sin(s·61)·2; dy += cos(s·47)·2 (±2 px jitter).
Result = `translationValues(dx, dy, 0)` then `rotateZ(angle)` when non-zero. All linear time, no easing; effects add.

`colorMatrix(modifiers, seconds)` (static, @visibleForTesting) → 4×5 row-major list or null when no tinted bit.
