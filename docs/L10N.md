# Localization (English and French)

ONSET speaks English and French. Every text a viewer reads, hears (screen
readers) or receives (notifications, the media notification, the
Picture-in-picture buttons) comes from the ARB files, in both languages, and
the tests in `test/l10n/` and `test/guards/` keep it that way. This page says
how to add a string, how the French and the English are written, and how to
read the guards when they fail.

## 1. How it works

| Piece | Where | What it does |
|---|---|---|
| ARB files | `lib/l10n/app_en.arb` (template), `lib/l10n/app_fr.arb` | One message per key, the same keys in the same order. English carries the metadata (`@key`: description, placeholders); French carries none. |
| Generated code | `lib/l10n/app_localizations*.dart` | Written by `flutter gen-l10n` (`l10n.yaml`: named parameters, non-nullable getter). Never edited by hand. The three files keep CRLF line endings: convert them after generating (`sed -i 's/\r$//; s/$/\r/'`). |
| Access | `lib/l10n/l10n.dart` | `context.l10n` in widgets (rebuilds on a language change); `L10n.current` where there is no widget (a chat notice put in the buffer, a notification). `L10n.english` is for `lib/l10n/` only. |
| Language setting | `SettingsStore.appLanguage` (`system`, `en`, `fr`) | Picked on the onboarding Intro, in Settings › Général › Langue, or once in a sheet for users from before French. `resolveAppLocale` turns System into the device's first supported language (fr-CA is French), English otherwise. |
| `LocaleSync` | `MaterialApp.builder` in `lib/main.dart` | Calls `L10n.use` (also `Intl.defaultLocale`) each time the shown locale changes, then its listeners: the saved copy for the background (`rememberUiLanguage`), the reminders worded again when the language changed, the media notification's buttons. |
| API errors | `lib/l10n/api_errors.dart` | `apiErrorText` words an `ApiException` by its kind; `chatErrorText` builds the chat's failure lines. `ApiException.message` stays English, for logs only. |
| Enum labels | `lib/l10n/enum_labels.dart` | `label(l)` extensions on settings enums and other values shown as words. |

Android 13+ also has a per-app language (Settings › Apps › ONSET › Language):
`lib/services/locale_bridge.dart` and the `onset/locale` channel in
`MainActivity.kt` keep it and the app's setting the same both ways. Picking
System in the app clears the per-app language, so the app follows the
device again. Once a per-app language is set, Flutter's own locale list is
that language, so Settings › Langue asks the system (`systemLocales`) to name
the language System would give.

## 2. Adding or changing a string

1. Add the key to `app_en.arb` **and** `app_fr.arb`, at the same position.
   Keys are camelCase with the feature first (`chatModFailed`,
   `vodReplayTitle`, `settingsLanguageTitle`).
2. Give the English key a `description`: where the text shows and what its
   placeholders hold, enough for a translator who never saw the screen.
   Mention length limits ("one line in a 360 dp field").
3. Declare every placeholder with a `type` and an `example`:
   - counts are `int`; a number shown in full uses
     `"format": "decimalPattern"` (« 10 000 », "10,000"), a short one
     `"compact"` (« 1,2 k »);
   - dates are `DateTime` with a format, or a `String` the code formats with
     `DateFormat(…, dateLocaleOf(l))`;
   - names, titles and other data are `String`.
4. Plurals: `{count, plural, one{…} other{…}}`. French `one` covers 0 and 1
   (« 0 spectateur », « 1 spectateur »), so use `one`, never `=1`. Keep the
   number inside the branches (`{count} viewers`).
5. Selects: an on/off select uses the `OnOff` names (`on`/`other`) and the
   code passes `OnOff.of(value).name`. A select whose `other` branch would
   be empty or vague must be listed in `test/l10n/select_coverage_test.dart`
   with every value the code passes.
6. Never build a sentence from pieces in code. A styled piece (a bold name, a
   link) goes through `l10nMark(i)` as the placeholder's value and
   `l10nSpans(message, pieces)`, so each language puts it where its grammar
   wants.
7. Run `flutter gen-l10n`, restore CRLF on the three generated files, then
   `flutter analyze` and `flutter test test/l10n test/guards`.
8. English and French go in the same commit.

**Extracting existing English text is a pure refactor:** the English value
must be byte-identical to the literal it replaces, so the English tests keep
passing. Rewording English is a separate, deliberate change, following the
English style guide (section 4).

**What is not translated** (and is listed in `test/guards/l10n_allowlist.dart`
with its reason): brand names (ONSET, Twitch, 7TV), Twitch's own data (stream
titles, names, badge titles, IRC notices as Twitch sends them), code that
only looks like text (GraphQL, IRC lines, sort values, cookie names), log and
exception messages (`ApiException.message`), and endonyms (« Français »).
Twitch's chat commands (`/ban`, `/timeout 600`, `10m`) are never translated
either: Twitch parses them; only their descriptions are.

**Twitch's content rule:** text written by a person (titles, chat messages,
names, reasons typed by a moderator) stays as written. Any sentence the app
can build from tags is translated: on a French screen the app writes its own
sentence from the IRC tags (raids, gifts, subs); on an English screen it may
keep Twitch's own `system-msg`, as it always did.

## 3. French style guide

### Voice

- **vous** everywhere, with polite imperatives: « Appuyez sur… »,
  « Réessayez ». Never « Touchez » or « Cliquez ».
- Errors: « Impossible de … » and « Une erreur inattendue est survenue ».
- Sentence case for titles, buttons and tabs, never Title Case. Days and
  months in lower case inside a sentence; a date heading starts with a
  capital (« Dimanche 1er novembre »).
- Natural and concise: prefer the noun form when room is short
  (« Exclusion temporaire », « Bannissement définitif », « Envoi
  impossible »), and check at 360 dp ×1,3 that the whole phrase fits, not
  only the value.
- A screen-reader hint for an action is an infinitive in lower case
  (« afficher les options du message »).

### Typography

Checked by `test/l10n/fr_typography_test.dart` on every French value and on
`assets/release-notes.fr.md`.

| Rule | Example |
|---|---|
| U+202F (narrow no-break space) before `;` `!` `?` and `%` | « C’est fait ! », « 50 % » |
| U+00A0 (no-break space) before `:` and inside « » | « Motif : … », « « Auto » » |
| No space before `.` `,` `…` | « Chargement… » |
| Curly apostrophe ’ only, ellipsis … only, quotes « » (nested “ ”) | « l’application » |
| Accented capitals | « À suivre », « Événements » |
| Number and unit with U+00A0, compound durations too | « 5 min », « 2 h 14 min », « 10 s », « 12 heures » |
| Thousands with the language's separator (`decimalPattern`) | « 10 000 caractères » |
| Short numbers | « 1,2 k », « 12,6 M », « 1,1 Md »; never a lower-case « m » for millions |
| Multiplier | « 1,25 × », with U+00A0 and U+00D7 |
| Ordinals | « 1er », « 2e » |
| Countdowns stay numeric | « 4:29 », « 1:02:15 » |
| No inclusive-writing dot | rephrase neutrally |

The ARB files write the invisible spaces as ` ` and ` `, so they
can be seen in a diff.

### Grammar rules

- **No elision before a dynamic name.** « de », « le », « que » never stand
  right before a placeholder that holds a name: « d’Ami » cannot be built.
  Rephrase: « Le live de la chaîne {name} commence », « {sender} vous
  mentionne… ». Elision before a fixed brand is fine (« d’ONSET »).
- **No agreement with a dynamic name or with « vous ».** Use noun forms or
  present tenses: « Votre session a expiré », « Abonnement : {name} »,
  « {name} est en direct ». No gender `select`.
- **live** is masculine (« un live », « ce live »); « diffusion » only for
  videos (« Ancienne diffusion »); « stream » never on screen.
- **emote** is feminine (« Emotes globales »).
- **Failure lines:** « Impossible de X. {motif}. Raison de Twitch :
  « {texte} » ». The worded kind always ends with a full stop (or its own
  `!` `?` `…`) before « Raison de Twitch » and when it stands alone; no full
  stop after the closing » when Twitch's words end with one. Twitch's
  English is quoted only when short (`maxQuotedTwitchReason`) and never
  stands alone. `chatErrorText` applies this; English keeps Twitch's own
  words as the chat always showed them.
- **Lists of settings cited in a sentence** use the chevron:
  « Paramètres › Général », with the page titles exactly as on screen.
- **Placeholders and one-line bars** (chat input, restriction bar) must keep
  the value visible at 360 dp ×1,3: short noun forms, value first.

## 4. English style guide

The English is written as a polished US app, in Twitch's own voice: plain,
concise, second person, contractions welcome ("can't", "you'll"). Checked by
`test/l10n/en_style_test.dart` on every English value and on
`assets/release-notes.md`.

### Spelling and words

- **US English:** color, canceled, toward, reorganized, analyze.
- **Log in** (verb), **login** (noun and adjective), **logged in**. Never
  "sign in" or "signed in".
- **Tap**, never "click"; **double-tap**, **long-press**, **swipe**.
- **Failures:** "Couldn't …" ("Couldn't load clips."), never "Unable to",
  "Failed to" or "… failed". No "Please": "Try again.", "Log in again to
  continue."
- **Serial comma:** "subs, gifts, or Bits"; "Theme, stream cards, browsing,
  and links".
- **Compound modifiers** take a hyphen: first-time chatters, most-viewed
  videos, a 6-month sub, a 12-stream streak, full-screen mode (but "full
  screen" as a noun: "Exit full screen").

### Capitals

- **Sentence case** for every UI element: titles, buttons, tabs, labels,
  menu items, settings rows, section headers, chips, tooltips, Android
  notification channel names ("Edit chat filters", "Wi-Fi only", "Up next",
  "Closed captions", "Chat mentions").
- **Proper nouns and Twitch's product names keep their capitals:** ONSET,
  Twitch, Hype Train (and its Golden Kappa, Treasure, Community, Mythic and
  Shared trains, the Hype Meter), Watch Streak, Bits, Prime, Turbo,
  AutoMod, Tier 1, 7TV, BetterTTV, FrankerFaceZ, Picture-in-picture as the
  system feature's name in a sentence ("picture-in-picture" otherwise).
- **Subs** are lower case in the app's own words: "a gift sub", "5 subs",
  "Gift a sub", "a Tier 1 sub".
- **Screens and options** cited in a sentence keep the case they have on
  screen: "in Settings › General", "log in later from Profile", "“Speed
  up” plays slightly faster".
- **ALL CAPS** only for small badges and eyebrows the design writes in
  capitals (LIVE, NEW BUILD, UP NEXT, WHAT'S NEW).

### Punctuation

| Rule | Example |
|---|---|
| Curly apostrophe ’, never ' | "Couldn’t", "Twitch’s" |
| Curly double quotes “ ” around a name, an option or the viewer's words; never single quotes or straight ones | "Go to channel “{query}”", "Removed “spoiler”" |
| The ellipsis character … (no space before), never three dots | "Connecting to chat…", "Checking…" |
| Spaced em dash for a break inside a sentence; middle dot · between status fragments; en dash for a range | "Linked accounts — on twitch.tv", "Not logged in · you can log in later", "Name (A–Z)" |
| Full sentences (dialog bodies, settings descriptions, snackbars that are sentences, chat lines the app writes) end with a period; fragments (titles, buttons, labels, chips, empty-state headlines) do not | "Shows a card under messages that link to a Twitch clip or video." / "No recent searches" |
| Error messages are complete sentences and end with `.`, `!` or `?`, even as an error screen's headline; their description starts with "Error message." | "Couldn’t load streams.", "Channel not found." |
| A hint a screen reader reads after its own "Double-tap to" is a lower-case verb phrase | "open message options", "show details" |

### Numbers and units

- **Plurals** go through ICU with a `one` branch for every count, even
  where English reads the same ("{count} new"): `{count, plural, one{…}
  other{…}}`.
- **Compact units, attached:** seconds, minutes and hours in tight places
  ("10s", "4m 30s", "3h 12m"), the percent sign ("50%"), the multiplier
  sign × ("2.5×", "1.25×"). In a sentence a duration is spelled out ("10
  seconds", "24 hours", "1 week"). Data units keep their space, as the SI
  writes them ("38.0 MB", "6.2 Mbps", "60 fps").
- **Durations** of moderation are worded with the largest whole unit ("10
  minutes", "1 week", "3 months"), the same in every line that shows one
  (timeouts, follow ages).

### Labels the policy cites

`PRIVACY.md` quotes some settings labels word for word, and
`test/guards/site_privacy_sync_test.dart` checks that they still exist. Such a
label changes together with the policy, never alone: "Show GIFs in Chat" keeps
its capital until the policy is updated with it.

## 5. Background isolate and notifications

- The background go-live check runs in its own isolate with no
  `MaterialApp`: `useBackgroundLanguage` picks the language with
  `uiLanguageIn` (the language picked in the settings; with System, the
  device's first supported language; then the `ui_language` the app last
  saved; then English), calls `initializeDateFormatting` itself (there are no
  localization delegates to load the date symbols), then `L10n.use`.
  Preferences that cannot be read fall back to English, are reported, and
  the check goes on.
- Builders of notification text take an `AppLocalizations` (`goLiveNotice`,
  `GoLiveNotifications.show`, `MentionNotifications`, `LocalReminderPlatform`);
  never read `L10n.current` deep inside a background path.
- Android channel names and descriptions are passed on every notification
  with `channelAction: AndroidNotificationChannelAction.update`, so an
  existing channel takes the new language. Android only renames the channel
  and changes its description (importance can only go down, and only while
  the viewer has not changed the channel); the viewer's own settings for the
  channel stay.
- The system keeps a scheduled notification's text. `rememberUiLanguage`
  saves the shown language and, only when it differs from the one saved
  before (at once, or while the app was closed), words the reminders again
  (`ScheduleReminders.reschedule`). Reminder changes (toggle, schedule sync,
  rewording, handing due ones to Activity) run one at a time.
- Stored data is never translated: store codes and parameters, and word
  them when shown (`ActivityEntry.params`, the go-live problem code
  `logged_out`). Entries stored before keep their stored English words.
- The media notification's buttons come from Dart (`mediaLabelsOf`) through
  the background audio channel. The Picture-in-picture buttons are Android
  resources of the vendored plugin (`values-fr/strings.xml`); below
  Android 13 they follow the device's language, not the app's (see
  `packages/simple_pip_mode/VENDORED.md`).
- iOS declares both languages in `Info.plist` (`CFBundleLocalizations`) and
  `knownRegions`.

## 6. Guards and how to read their failures

| Test | Fails when | What to do |
|---|---|---|
| `test/guards/no_hardcoded_strings_test.dart` | A literal of `lib/` reads like UI text (in a place that shows text, or a sentence anywhere). The baseline (`l10n_baseline.dart`) is empty and stays empty. | Move the text to the ARB files. If it is truly never shown or never translated, add it to `l10n_allowlist.dart` with an accurate reason. An allow-list entry that no longer matches a literal also fails: remove it. |
| `test/guards/l10n_language_lookups_test.dart` | `L10n.english` is used outside `lib/l10n/`, or a language is looked up by name (`lookupAppLocalizations`, `AppLocalizationsFr`, `Localizations.override`) outside the listed uses. | Read `context.l10n` or `L10n.current`. |
| `test/guards/l10n_wiring_test.dart` | `MaterialApp` in `lib/main.dart` lost its delegates, supported locales, locale, resolution callback or `LocaleSync`. | Restore the wiring. |
| `test/guards/android_l10n_test.dart` | An English literal in a Kotlin `NotificationChannel(` or `action(`; a key of the vendored Picture-in-picture plugin without French; `locales_config.xml` or iOS's localizations not matching `supportedLocales`. | Pass the words from Dart; add the French resource; update the language lists together. |
| `test/l10n/arb_parity_test.dart` | Keys or order differ, an English key has no description, a placeholder is untyped or differs, a plural lacks `other` (or French `one`), a value is empty or invalid ICU, French equals English without being listed in `_sameInBothLanguages`, or the generated code is stale. | Fix the ARB files; run `flutter gen-l10n`. |
| `test/l10n/fr_typography_test.dart` | A French value breaks a rule of section 3 (the message names the key and the rule). | Fix the typography in `app_fr.arb`. |
| `test/l10n/en_style_test.dart` | An English value (or a line of `assets/release-notes.md`) breaks a rule of section 4: a straight apostrophe or quote, three dots, "sign in", Title Case, a space at an edge or a double space, or an error message (its description starts with "Error message.") that does not end with `.`, `!` or `?`. | Fix the English in `app_en.arb`. A capital that is no Title Case (a sentence in a placeholder before it) or an error ending with a placeholder that holds a whole sentence is listed in the test with its reason. |
| `test/guards/text_style_font_test.dart` | A `textStyle:` (a button's or a tooltip's) is a `TextStyle(...)` without a `fontFamily`: it replaces the inherited style, so the label would draw in the platform's font instead of Inter. | Add `fontFamily: OnsetTokens.bodyFamily`. |
| `test/l10n/select_coverage_test.dart` | A select that can fall back to an empty or vague `other` is not listed, or a value the code passes has no words of its own. | List the select with its values; give each value a branch. |
| `test/l10n/inter_font_test.dart` | A bundled Inter face lacks a character the ARB files use. | Use another character, or bundle a face that has it. |
| French screen tests (`test/l10n/fr_*_test.dart` and the `in French` groups of the screen tests) | `expectFrenchThroughout` found an exception (overflow), an English text (`englishLeaks`), a text cut off without an ellipsis (`clippedTexts`), or an app's own label or sentence ended by an ellipsis (`ellipsizedAppTexts`: names and titles may be shortened, the app's words may not); some also check `ellipsizedTexts` on a part of the screen where no word may be lost (a banner's subtitle, a one-line bar). The failure names the window, the text scale and the text. | Shorten the French, or let the layout give the words room. A leak in a chat line that is Twitch's or a viewer's own words is passed as `content:`; an app message passed as content fails the test. |

The French screen tests run at five windows (`frenchScreenSizes`: 360×640,
390×844, the landscape phone 844×390, and the tablets 1280×854 and 854×1280)
and two text scales (`frenchTextScales`: ×1.0 and ×1.3), in the real Inter
font (`pumpLocalized` / `localizedApp`). The main screens (settings, chat,
the channel's player and info row, Home's sections) run again in English
(`sweepLocales`, the test names end in "in English") at the same windows and
scales: `expectFrenchThroughout` then checks everything but the leaks, so an
English label that runs longer is caught too.

## 7. Before committing a change with text

- [ ] English and French values, same key order, English description.
- [ ] `flutter gen-l10n`, CRLF restored on the generated files.
- [ ] English byte-identical unless the change is meant to reword it; a
      reworded English follows section 4.
- [ ] `flutter analyze` clean, `flutter test test/l10n test/guards` green, and
      the screen's own tests (with its French group) green.
